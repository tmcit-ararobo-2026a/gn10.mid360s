# Overview
To enable this extension, run Isaac Sim with the flags --ext-folder {path_to_ext_folder} --enable {ext_directory_name}

This extension provides an Isaac Sim extension that simulates the Livox Mid-360S LiDAR.
The output of the LiDAR can used in OmniGraph.
